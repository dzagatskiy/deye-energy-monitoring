# ADR 0001: Кілька інверторів, вибір інвертора у віджеті

**Статус:** прийнято, 2026-11-23

## Контекст

В акаунті Deye Cloud два інвертори на двох станціях. Користувач хоче явно вибирати інвертор, наприклад, щоб один віджет показував перший інвертор, а другий віджет показував інший.

## Рішення

1. **Ідентичність:** `InverterID` = серійний номер інвертора (`deviceSn`). Його використовують і Deye Cloud, і локальний логер, тож дані з обох джерел зводяться до одного інвертора.
2. **Виявлення:** `POST /station/listWithDevice {deviceType: "INVERTER"}` → `[InverterDescriptor]` (станція, онлайн, час останніх даних). `/device/list` для особистих акаунтів не працює.
3. **Дані розділені по інверторах:** кожен `TelemetrySample` має `inverterId`. Сховище, дедуплікація, `OutageTracker`, статистика й автономність рахуються окремо для кожного інвертора (`SampleSeries.grouped`).
4. **Налаштування по інвертору:** `InverterProfile` містить власну назву ("Дача"), батарею, поріг напруги, часовий пояс і, за бажання, локальний логер (host, serial). Облікові дані Deye Cloud спільні для акаунта і зберігаються в Keychain.
5. **Віджети (iOS 17+):** `AppIntentConfiguration` з `WidgetConfigurationIntent`, у якого параметр `inverter: InverterEntity` (`AppEntity`). `EntityQuery` віддає збережений список `InverterDescriptor` з App Group. Кожен екземпляр віджета (Small/Medium/Large/Lock Screen) зберігає свій вибір у «Edit Widget». Якщо інвертор не вибрано, віджет показує онлайн-інвертор із найсвіжішими даними.
6. **Оновлення:** `RefreshService` оновлює всі інвертори одним запитом `/device/latest {deviceList: [sn…]}` (до 10 за раз), а історію тягне для кожного інвертора окремо. Знімок для віджета (`WidgetSnapshot`) зберігається окремо для кожного інвертора, `TimelineProvider` читає знімок вибраного.
7. **Застосунок:** на Dashboard перемикач інвертора вгорі (за замовчуванням останній вибраний). Outages і Statistics фільтруються за вибраним інвертором. У Settings є список інверторів із профілями.

## Наслідки

- Кількість запитів історії зростає пропорційно кількості інверторів (2 запити на добу на інвертор через ліміт 5 `measurePoints`). При 2 інверторах це далеко в межах ~60 запитів/хв.
- Сповіщення (відключення, низький SOC) підписуються назвою інвертора і налаштовуються окремо для кожного.
- `AppIntents`/WidgetKit-частина живе в таргеті застосунку й віджета (потрібен Xcode). Ядро `EnergyCore` дає лише моделі й логіку.
